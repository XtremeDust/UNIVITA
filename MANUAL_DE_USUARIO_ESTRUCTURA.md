# Estructura del Manual de Usuario - Sistema UNIVITA

Esta estructura está diseñada para documentar el funcionamiento del Dashboard administrativo del sistema UNIVITA.

## 1. Introducción
*   **Propósito del Sistema**: Gestión integral de actividades universitarias (inscripciones, torneos, eventos, etc.).
*   **Audiencia**: Administradores y usuarios con permisos de gestión.

## 2. Acceso al Sistema
*   **Login**: Explicar la pantalla de inicio de sesión.
*   **Recuperación de Contraseña**: (Si existe funcionalidad).

## 3. Interfaz General (Dashboard)
*   **Barra Lateral (Sidebar)**: Menú principal de navegación. Funcionalidad de colapsar/expandir.
*   **Encabezado (Header)**: Información del usuario, notificaciones rápidas, botón de menú (móvil).
*   **Área de Contenido Principal**: Donde se cargan las diferentes vistas.

## 4. Módulos del Sistema
Detalle de cada sección disponible en el menú de navegación:

### 4.1. Home (Inicio)
*   Vista general o bienvenida al dashboard.

### 4.2. Normativas
*   Gestión y visualización de normativas vigentes.

### 4.3. Inscripciones
*   **Gestión de Equipos**: Tabla `Table_Teams` para ver/administrar equipos inscritos.
*   **Usuarios Inscritos**: Tabla `Table_Usuarios_Inscritos` para ver la lista individual de inscritos.
*   **Suscripciones**: Tabla `Table_Subscripts` para gestionar suscripciones.

### 4.4. Notificaciones
*   Centro de notificaciones del sistema.

### 4.5. Eventos y Actividades
Este módulo se divide en dos sub-secciones:
*   **Actividades Generales** (Eventos Generales): Gestión de eventos generales del campus.
*   **Gestión de Torneos**:
    *   **Torneos**: Tabla `Table_Torneos` para crear y editar torneos.
    *   **Juegos/Partidos**: Tabla `Table_Games` para programar y registrar resultados de juegos.

### 4.6. Deportes
*   Gestión de disciplinas deportivas disponibles.

### 4.7. Ofertas Académicas
*   Administración de las ofertas académicas visibles para los estudiantes.

### 4.8. Comentarios
*   Moderación o visualización de comentarios hechos en la plataforma.

### 4.9. Valoración
*   Sistema de ratings o calificaciones de eventos/servicios.

### 4.10. Infraestructura
*   Gestión de espacios físicos (canchas, aulas, auditorios, etc.).

### 4.11. Reportes
*   Generación de informes de uso y estadísticas del sistema.

### 4.12. Configuración
*   Ajustes generales del sistema y preferencias.

## 5. Funcionalidades Transversales
*   **Búsqueda y Filtrado**: Cómo usar los filtros en las tablas (si aplican).
*   **Exportación de Datos**: Cómo exportar reportes o tablas (PDF/Excel) si está disponible.
*   **Cerrar Sesión**: Ubicación y acción del botón de salir.
